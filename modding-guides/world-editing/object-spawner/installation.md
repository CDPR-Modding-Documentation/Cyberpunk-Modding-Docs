# Installation

{% hint style="success" %}
Make sure to always keep the mod and it's dependencies up to date
{% endhint %}

## Requirements

* First, download and install all requirements:
  * **ArchiveXL** **(**[**GitHub**](https://github.com/psiberx/cp2077-archive-xl/releases)**|**[**Nexus**](https://www.nexusmods.com/cyberpunk2077/mods/4198)**)**
  * **Codeware (**[**GitHub**](https://github.com/psiberx/cp2077-codeware/releases)**|**[**Nexus**](https://www.nexusmods.com/cyberpunk2077/mods/7780)**)**
  * **Red4Ext (**[**GitHub**](https://github.com/wopss/RED4ext/releases)**|**[**Nexus**](https://www.nexusmods.com/cyberpunk2077/mods/2380)**)**
  * **CET (**[**GitHub**](https://github.com/maximegmd/CyberEngineTweaks/releases)**|**[**Nexus**](https://www.nexusmods.com/cyberpunk2077/mods/107)**)**
  * **Redscript (**[**GitHub**](https://github.com/jac3km4/redscript/releases)**|**[**Nexus**](https://www.nexusmods.com/cyberpunk2077/mods/1511)**)**
  * **WolvenKit (**[**GitHub**](https://github.com/WolvenKit/WolvenKit/releases)**|**[**Nexus**](https://www.nexusmods.com/cyberpunk2077/mods/2201)**)**

## Download

* Next, download World Builder:
  * [GitHub latest release](https://github.com/justarandomguyintheinternet/CP77_entSpawner/releases/latest)
  * [Nexus Mods page](https://www.nexusmods.com/cyberpunk2077/mods/20660)

## Installing

* Install the mod as any other mod, by extracting the downloaded file into the base game directory, or using a mod manager
  * The base game directory is called `Cyberpunk 2077` and contains the folders `bin` and `archive`

{% hint style="info" %}
If you unzipped the file correctly, you will now have the following folder:

`Cyberpunk 2077\bin\x64\plugins\cyber_engine_tweaks\mods\entSpawner`
{% endhint %}

{% hint style="danger" %}
**Redscript error after updating to 2.0.0 or newer ?**

Delete the file `\Cyberpunk 2077\r6\scripts\entBuilder.reds`

This file has been moved to a sub-folder in next version 2.0.0.
{% endhint %}
